## Ownership and status maintenance

Angular presents these capabilities; Rust implements their policy and behavior. Tauri exposes typed commands/channels; adapters isolate external systems. Model inference belongs to llmster, persistence to Rust-owned SQLite. See the [responsibility map](architecture-sequence.md#responsibility-map).

After a minor merges, update this map using implemented/partially implemented/architectural-only/planned/missing and link to the accepted spec plus verification. A passing fake is contract evidence; it does not make an untested real runtime/provider supported. Never mark a future capability implemented because a route, type or roadmap heading exists.
