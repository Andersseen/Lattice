# Repository assessment

Inspected on 2026-09-06 at baseline commit `2e8eb7e` (`feat: add setup`). The working tree was clean. Manifests say `0.1.0`; [CHANGELOG](../../CHANGELOG.md) says no releases have been published. Version labels in the roadmap are future release scopes, not existing tags.

## Status vocabulary

- **implemented**: concrete behavior exists in source; verification limits are stated separately.
- **partially implemented**: a usable subset exists, with named gaps.
- **architectural-only**: a boundary/decision exists in documentation, without its implementation.
- **planned**: a desired capability has no implementation or detailed accepted behavioral spec.
- **missing**: an expected safeguard or delivery artifact is absent; this does not imply every absent future feature is a defect.

## Verification record

This is an inspection of existing behavior, not an implementation change. No dependencies were installed and no implementation tests were added or modified.

- `pnpm check`: passed. Turbo replayed cached TS lint/typecheck/unit tasks; Cargo ran successfully (3 tests), as did rustfmt, Cargo check and Clippy.
- `pnpm --filter @lattice/desktop test`: passed directly, without Turbo cache (2 tests).
- `pnpm build:web`: passed using Turbo cache. Bundle sizes in cached output are not fresh resource measurements.
- `pnpm --filter @lattice/desktop tauri:build`: passed; freshly rebuilt Angular production assets and the optimized native executable. This is `--no-bundle`, not an installer/signature/native-launch test.
- `pnpm e2e`: 2 tests passed. Initial sandbox run could not bind the local dev-server port (`EPERM`); rerunning with approved local server/browser access passed. No implementation change was needed.
- The environment emits a user-level npm configuration warning about an unset variable; it did not prevent these checks. No credential value was read.
- Remote CI, installable packages, signing, native launch, real IPC traversal and resource profiling have not been certified by these checks.

## Priority debts

1. **0.2:** establish Rust-owned wire DTOs, automated TS export/drift detection, one bridge normalization point, bounded dynamic safe errors, actual IPC integration evidence, strict Angular template checking and test-source typechecking.
2. **0.3:** enable and verify production CSP and explicit command/window exposure before opening process or network capabilities; capture baseline resources.
3. **0.4:** introduce SQLite only for its first real consumer: non-secret settings. Define migrations and failure recovery before conversations/tasks.
4. **0.5–0.7:** distinguish runtime discovery, daemon/server ownership and model state; never equate OpenAI compatibility with lifecycle support.
5. **0.10 / 0.14 onward:** credentials before remote traffic, workspace policy before tools, task-specific grants before unattended work.
6. **0.25–0.28:** measured resource behavior, adversarial security verification, actual packaging and first-use/upgrade qualification close v1; they do not defer earlier safeguards.
