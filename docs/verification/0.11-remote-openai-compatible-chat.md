## Findings from implementation

- `ureq` 3.4.1 reports a body-phase deadline as an `io::Error` of kind `Other` wrapping `ureq::Error::Timeout`, not as `ErrorKind::TimedOut`. `is_timeout` checks both. Before this, 0.8's local adapter reported a deadline as "disconnected".
- The 0.8 orchestrator could report `failed` when the reader thread exited on cancellation and the channel disconnected before the orchestrator's next poll. Cancellation observed after any receive now wins.
- Volt UI's `select[voltNativeSelect]` gets its accessible name through `volt-form-field`/`volt-label`. A plain `<label for>` did not name it, so the Chat header select uses `aria-label="Provider"`.
- A Playwright race: right after clicking **Send**, the composer could still read as enabled before the zoneless render disabled it. The journey therefore waits for the reply text to finish and the cursor to disappear, not for the textbox to be enabled.
