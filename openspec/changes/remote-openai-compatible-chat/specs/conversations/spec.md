# Conversations Specification Delta

## ADDED Requirements

### Requirement: Lattice SHALL Record Provider And Model Provenance Per Assistant Message

Lattice SHALL record, for every assistant message, the provider key and model key of the target that generated it, and SHALL preserve earlier messages' provenance when later requests use a different target.

#### Scenario: Switching Local To Remote To Local Retains History And Provenance

- **GIVEN** a conversation with a reply generated locally
- **WHEN** the next reply is generated by a remote profile and the one after that locally again
- **THEN** reopening the conversation returns every message in order
- **AND** each assistant message reports the provider key and model key that generated it

#### Scenario: Provenance Never Contains Endpoint Or Credential Data

- **GIVEN** an assistant message generated by a remote profile
- **WHEN** the message is read
- **THEN** its provenance names only the provider key and model key
- **AND** contains no endpoint URL, credential identity or secret
